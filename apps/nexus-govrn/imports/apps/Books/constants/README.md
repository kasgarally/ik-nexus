# Constants

Stable strings and enums shared by schema, forms, and views: `listKey` values, status codes, matrix axis labels. Prefer named exports over magic strings in Vue files.

## Contents

- [What belongs here](#what-belongs-here)

## What belongs here

- `listKey` / owner-type strings
- Status and type enums
- Not Meteor collection instances (those stay in `collections/`)
