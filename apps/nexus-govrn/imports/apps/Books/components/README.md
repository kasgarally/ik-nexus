# Components

Vue widgets that belong to **this** sub-app (a risk matrix, a heat map, a score chip). Screens, views, and forms import them here.

If a second Meteor app needs the same widget, move it to `@nexus/ui` with an `N` prefix.

## Contents

- [What belongs here](#what-belongs-here)

## What belongs here

- Multi-view widgets (matrix, chart, stepper) used only by this sub-app
- Not page shells (`screens/`, `views/`) and not capture forms (`forms/`)
