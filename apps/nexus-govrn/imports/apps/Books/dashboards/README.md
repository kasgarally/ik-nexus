# Dashboards

On-screen dashboard layouts for **this** sub-app: KPI strips, charts, and summary cards that watch live data. One Vue file per dashboard composition.

## Contents

- [What belongs here](#what-belongs-here)

## What belongs here

- Dashboard shells and widget arrangements used only by this sub-app
- Not printable A4 pages (`reports/`) and not landing tiles (`workspace/`)
- Not reusable chart widgets if several views share them (`components/`)
