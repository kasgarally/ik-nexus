# Reports

Vue (or print CSS) components that lay this sub-app’s data out as an **A4** page: margins, page breaks, headers/footers, and a print stylesheet. Designed to print or export as a paginated document.

## Contents

- [What belongs here](#what-belongs-here)

## What belongs here

- A4 report templates (cover page, register listing, detail sheet)
- Print-only styles for that page size
- Not CSV / download shaping (`exports/`) and not on-screen dashboards (`dashboards/`)
- Not the GridFS HTTP route (`@nexus/files`)
