# Views

`Vew…` Vue files for the WebLayout **default** (register) and **context** (selected book) named views. Subscribe here. Open forms in `NModal`. Vue `v-if` on roles is display only.

## Contents

- [What belongs here](#what-belongs-here)

## What belongs here

- `VewBooks.vue` — register; row click pushes `/books/:id`
- `VewBook.vue` — context pane: detail, files, `NAdminConfigCard`
- `VewBookCategories.vue` — `NListItemsEditor` for `books.category`
- Not page headings (`screens/`) and not the form fields (`forms/`)
